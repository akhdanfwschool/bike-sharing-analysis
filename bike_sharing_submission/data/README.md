# Dataset

Folder ini menampung file asli `day.csv`, `hour.csv`, dan `Readme.txt`. Dari root proyek jalankan:

```bash
python scripts/download_data.py
```

File CSV tidak dibundel dalam arsip yang dibuat di lingkungan ini karena unduhan eksternal tidak dapat diakses dari runtime pembuatan. Skrip mengunduh dataset asli; jangan menggantinya dengan data sintetis. Sebelum submission akhir, pastikan dataset yang digunakan benar-benar disertakan di folder ini sesuai ketentuan kelas.
